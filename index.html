      • Discrete Manifold Modeling Engine: Custom native boundary evaluation algorithms (buildBoxManifoldCut, createPipeSolidGeometry, Catmull-Rom spline curves) maintaining Euler characteristic χ = 2 and watertight 2-manifold boundary topology.
      • Mesh Loaders: Official Three.js STLLoader (ASCII & binary) and OBJLoader (Wavefront text geometry).
      • Audio Subsystem: ElevenLabs Voice Synthesis (voice of Cubert), Web Audio API dynamic synthesizers, and real hold-music playback.
      Kernel Audit Notice: CADN'T contains zero code from proprietary solid modeling kernels (Parasolid, ACIS, Granite, or Open CASCADE). All discrete boundary modifications are computed natively in JavaScript.
